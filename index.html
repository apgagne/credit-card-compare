About These Valuations

Point valuations are not set by card issuers — they are independent estimates from rewards analysts. Actual value you receive depends on how you redeem. Cash back / statement credits typically yield the floor value; transfer partner sweet spots can yield 2–5× or more for premium flights.

To update valuations: edit data/points-valuations.json. Each currency has a cashbackCpp and transferCpp field (cents per point). The website automatically picks up any changes.
